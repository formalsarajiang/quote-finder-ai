# quote-finder-ai
Finds Quotes for Virtue

On this website, you can click on one of three virtues: intelligence, resilience, and compassion. Upon clicking a button, the website will randomly show one of five quotes that Claude picked that aligned with the chosen virtue. Clicking another button or the same button again will random select another quote that aligns with the selected virtue.

Generated with Claude Sonnet 4.6

Made for University of Chicago's AI Immersion Week (Summer 2026 Career Trek)
